# Jalali Appointment Calendar

Jalali calendar built with React + TypeScript + Tailwind CSS using date-fns-jalali.
Inspired by FullCalendar. The header lets you control the month and year, change the date, and switch between day / week / month views.
## Technologies Used

- React.js
- TypeScript
- Vite
- Tailwindcss
- date-fns-jalali
